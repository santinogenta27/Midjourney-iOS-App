# Visual Creator AI — iOS App

Native iOS application built with SwiftUI that generates images and videos using AI from text prompts, with basic editing, content moderation, and cloud sync.

---

## Overview

The app works as a client for visual content generation: the user types a prompt, the app validates/translates it, sends it to an image generation service (Midjourney-style) or a video generation service, and displays the result in a chat-style feed, with actions to create variations, upscale, blend images, edit, and share.

It includes an in-app subscription model to unlock advanced features, plus both local persistence (for fast/offline access) and cloud sync (to keep content in sync across sessions).

---

## Key Features

### Image generation
- Text-prompt-based image generation, displayed in 2x2 grids (Midjourney-style).
- Variations of a generated image (V1–V4 buttons).
- Upscaling of a specific image from the grid (U1–U4 buttons).
- "Vary Strong" / "Vary Subtle" and "Upscale Subtle" / "Upscale Creative" on an already generated image.
- "Redo Upscale" (repeat the upscale).
- **Blend**: combine several user-uploaded images (photo picker) into a newly generated image.

### Video generation
- Prompt-based video generation, with an optional reference image (integration with the Pika Labs API).
- A toggle to use an alternative generation model (integration with the Minimax API) as a second option.
- In-app video playback (AVKit) and thumbnail generation for the session history.

### Image editing & actions
- Full-screen detail view with zoom.
- **Remix**: free-hand drawing on the generated image (PencilKit), a subscriber-only feature.
- **Magic Wand**: automatic image enhancement (brightness, contrast, saturation, exposure, sharpness, and vibrance) through a Core Image filter pipeline, also subscriber-only.
- Saving images/videos to the camera roll (Photos framework).
- Sharing content via the native iOS activity sheet (`UIActivityViewController`).

### Content moderation
- A local blocklist of prohibited words that blocks prompts before they're sent for generation.
- Text checks against Google's Perspective API (toxicity, insults, threats, sexually explicit content) before generating.
- Checks on user-uploaded images against the Google Cloud Vision API (SafeSearch) to block inappropriate content in the blend feature.

### Multi-language support
- Automatic language detection of the prompt and translation into English (Google Cloud Translation API) before sending it to the generation service.

### Subscriptions & in-app purchases
- Native paywall ("Visual Creator Plus") implemented with StoreKit (`SKPaymentQueue`, `SKProductsRequest`).
- Subscription status persisted securely in the Keychain (via `KeychainSwift`).
- Purchase restoration.
- Free-attempt limit also managed through the Keychain.

### Persistence & sync
- **Firebase Firestore**: stores metadata for each generated image (prompt, URL, timestamp, jobID) and syncs in real time via snapshot listeners, allowing users to see content generated by others in the community chat.
- **Firebase Storage**: uploads the reference images used in the blend feature.
- **Core Data**: caches generated images locally (for fast loading and offline use), with automatic cleanup of images older than one month.
- A community-wide counter of generated images, updated atomically using Firestore transactions.

### Navigation & structure
- A community chat (images visible to all users) and a private chat (independent, with its own generation logic).
- A settings menu with: access to video generation, restore purchases, usage guides, and links to Terms of Use / Privacy Policy (hosted on Google Sites).

## Tech Stack

- **UI**: SwiftUI, Combine
- **Backend/Cloud**: Firebase (Firestore, Storage)
- **Local persistence**: Core Data, Keychain (`KeychainSwift`)
- **Payments**: StoreKit (in-app purchases / subscriptions)
- **Media**: PhotosUI / Photos (picking and saving), AVKit/AVFoundation (video playback and thumbnail generation), PencilKit (drawing on images), Core Image / CIFilterBuiltins (image enhancement filters)
- **Networking**: plain `URLSession`, consuming several third-party REST APIs:
  - Image generation: a Midjourney-style API via useapi.net
  - Video generation: the Pika Labs API via useapi.net, plus the Minimax API as an alternative model
  - Text moderation: Google's Perspective API (Comment Analyzer)
  - Image moderation: Google Cloud Vision API (SafeSearch)
  - Translation/language detection: Google Cloud Translation API

## What I Learned Building This

- Integrating multiple third-party REST APIs (image generation, video generation, moderation, and translation), coordinating async calls and background job-status polling.
- Implementing an end-to-end in-app subscription system with StoreKit, including purchase restoration and secure persistence of entitlement state with Keychain.
- Designing a hybrid sync layer (Core Data for local caching + Firestore for real-time updates) to keep the experience smooth with or without a connection.
- Applying multiple layers of content moderation (local blocklist + third-party APIs) on both text and images before generating content.
- Working with Core Image to build a chained filter pipeline for automatic image enhancement.
- Integrating PencilKit to add a manual editing layer on top of AI-generated content.

---

## Notes / Next Steps

- API keys and auth tokens are currently hardcoded in the source code; before making the repo public, these should be moved to environment variables or a config file excluded from version control.
- Most of the business logic currently lives inside SwiftUI Views; refactoring toward a more decoupled pattern (e.g., MVVM) would simplify maintenance going forward.
